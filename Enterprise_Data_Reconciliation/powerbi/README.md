# Power BI — Enterprise Data Reconciliation

## Intended dashboard
1. KPI cards: Total USD Revenue, Final Transactions, Latest Active Users, ERROR Logs.
2. Line chart: Month -> Total USD Revenue.
3. Bar chart: Customer -> Total USD Revenue, Top N = 5.
4. Slicers: Month, User_ID, Product_ID.
5. Detail table: Date, User_ID, name, Product_ID, Euro_Value, EUR_to_USD_Filled, USD_Revenue.

## Source
Use `../data/reconciled_transactions.csv` as the main fact table.
Use `../data/monthly_revenue.csv` and `../data/top5_customers.csv` for audit snapshots.

## DAX
Total USD Revenue = SUM(ReconciledTransactions[USD_Revenue])
Transaction Count = COUNTROWS(ReconciledTransactions)
Average Transaction USD = DIVIDE([Total USD Revenue], [Transaction Count])
Top 5 Revenue = CALCULATE([Total USD Revenue], TOPN(5, VALUES(ReconciledTransactions[User_ID]), [Total USD Revenue], DESC))

## Important
The ZIP contains a PBIP/TMDL source project and build instructions rather than a binary `.pbix` file. A `.pbix` is a Power BI Desktop binary artifact and is not generated by this environment. Open the `.pbip` project in Power BI Desktop and refresh/rebind the CSV path if required.
